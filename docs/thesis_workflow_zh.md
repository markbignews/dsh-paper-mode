# 论文 AIGC 痕迹检测与改写：闭环流程方法论

> 配套仓库：cn-thesis-aigc-detector。本文说明"从拿到论文到交付定稿"的完整工作流，以及每一步的判定依据；语言特征与改写细则以 `references/aigc_signals_zh.md` 为准，本文不再重复细节。

## 0. 三条底线（贯穿全程）

1. **估算 ≠ 官方结果**。一切按知网等 AIGC 检测的**语言特征**做的估算，都不是知网/维普/Turnitin 的官方判定；官方实测才是最终标准。每次汇报估算值都必须附带这句话。
2. **不得编造**。改写不得编造数据、实验、案例、引用；没有证据支撑时，宁可弱化语气、补充边界，也不伪造，更不得为"降率"保留或新增捏造内容。
3. **必须保留**。事实、数字、术语、公式、图表引用、引用编号、结论方向、学术语体（不口语化）在改写中一律不动。

## 0.1 论文初审（值不值得改；先于参数确认与任何检测）

拿到可判读的全文/章节文本后**最先执行**（单段局部精修请求按"片段自洽性"轻量执行；用户明确"直接改、不用审"可跳过并注明）。

- **执行方式**：多 agent 宿主由 **角色A · 论文初审子代理**（全新上下文、任务包自带初审模板）执行，主 agent 不自行判定、不预置结论；单 agent 宿主由主 agent 按同一模板自查并注明。
- **初审四维**：① 立意与选题（题目-内容一致、问题成立、有贡献点）；② 结构与论证（逻辑连贯、论证链完整、结论有支撑）；③ 前后一致性（术语/数据/观点矛盾，须给两处相抵原文）；④ 内容质量与完成度（信息密度、套话空泛、整段雷同或拼凑抄袭）。外加可改性评估：问题属"定点可修"还是"需重写"，降率约束下能否改到可用。
- **裁决**：照录呈现初审报告——❌ **不值得改**：说明硬理由并**退出本流程**（可建议先重写框架/与导师对齐/涉抄袭不得代改；用户坚持则注明风险继续）；⚠️：先解决作者侧硬问题再继续；✅：进入需求参数确认。

## 0.5 开始前：需求参数确认（每次先问；上下文已有不重复问）

任何论文处理开始前先核对四项参数，**会话上下文已明确给出的不重复问**，只问缺失项，并用一句话复述确认（同一篇论文连续处理不重复问，换新论文/新任务重新核对）：

1. **目标优先级**：只降 AIGC 率 / 只降查重率 / 两者都做。两者都做时**默认先降查重率到目标、再降 AIGC 率到目标**（先处理与语料重合的段落可顺带消掉大量 AI 特征，之后 AIGC 轮只需定点句法微调；AI 生成占比极高的论文可临时改为先降 AIGC）；用户指定其他顺序则从其指定。
2. **学历级别**：本科 / 硕士 / 博士——用于给出查重合格线经验建议与行文分寸。
3. **论文级别（类型）**：本科毕业论文 / 硕士学位论文 / 博士学位论文 / 期刊论文（普刊或核心）/ 会议论文 / 课程论文等。
4. **目标比例**：AIGC 估算率 ≤？%（未指定默认 ≤10%）；若含查重：查重率 ≤？%（未指定按学历建议——本科 ≤30%、硕士 ≤20%、博士 ≤15%——以用户确认为准）。

查重相关的机制与降重策略另见 `references/duplicate_check_zh.md`（与 AI 率同构：本地只做风险估算，官方报告为准）。

**角色与轮次（多 agent 宿主）**：任何检测/自查都由**全新上下文**的独立子代理完成——角色A 论文初审最先执行（判定值不值得改，❌ 即退出）；角色B 引述核查恒先行于指标轮次；两者都做时按轮执行，默认**查重轮在前**（角色C 查重风险自查 → 降重意见 → 确认 → 改写 → 新角色C 复查），随后 **AIGC 轮**（角色D 检测 → 意见 → 确认 → 改写 → 新角色D 复查）。只做单项则只跑对应轮；全部轮次达标后，由 **角色E · 改后终审子代理**（全新上下文）对改后全文做交付前审核（合规/内容保真/论证/语体 + 残留风险），✅ 通过才导出交付，⚠️/❌ 定点返修后重开新角色E 再审；无子代理的宿主按对应版本 SKILL 的单 agent 降级与盲评路径执行，纪律不变。

**统一命名与执行排序**：角色A 论文初审 → 角色B 引述核查 → 角色C 查重自查 → 角色D AI 率检测 → 角色E 改后终审（字母=默认执行序；需求参数指定先降 AIGC 时仅 C/D 互换）。

## 1. 整体闭环

```
⓪ 论文初审（角色A：值不值得改；❌ 即退出）
→ 需求参数确认（优先级/学历/论文级别/目标比例）
→ ①引述核查（角色B） → ②轮次自查/检测（默认先查重轮角色C，后 AIGC 轮角色D）
→ ③修改意见（与作者确认） → ④逐段改写
→ ⑤独立复查（新角色C/B 重估） → 未达标回到 ③/④ 定点改最红的段
→ 全部轮次达标 → ⑥终审（角色E：改后全文交付审核，⚠️/❌ 定点返修再审）
→ ⑦精确导出定稿 → 作者上官方平台实测 → 标红段落回传，进入二次精修
```

## 2. 阶段 ①：引述/引用可靠性核查（前置，先于任何检测）

顺序不可颠倒：引述没核清之前，不做 AI 率检测。

- 把全文的引述逐条编号：作者+年份、文献题名、引文、数据/图表来源、机构/人名、方法出处、URL/编号。
- **逐条独立核验**：建议每条引述由一个不带上下文先验的独立评估者查证（可用 `web_search`/`web_fetch`），要点：来源是否真实存在、内容是否支撑所引主张、数据是否有出处。评估者不得预置"原文大概率没问题"的倾向。
- 汇总三条判定：✅ 可查证且真实支撑结论；⚠️ 信息对不上或查不到但无法排除；❌ 疑似捏造。
- ⚠️/❌ 必须向作者**明示**——这是独立于 AI 率的问题，不能靠改写掩盖。处理：有可靠同义来源则替换为真实来源；否则删除该引述、弱化论断或补边界。**不得编造"替身来源"。**

## 3. 阶段 ②：AI 率检测估算

- **独立评估原则**：每一次估算——首次检测与每轮改写后的复查重测——都由一个**不携带前序对话/改写记录**的独立评估者执行，避免"改写着自测"的乐观偏差与前序判定锚定。主流程只提供方法（信号库路径、扫描脚本、判定标准），不提供此前的判定结论；复查轮可附上"上一版报告供对照"，但评估者须先独立判定。
- 机械步骤：
  1. 把全文落盘为 `.txt`（或直接用 `.docx`）；
  2. 跑确定性扫描 `python3 scripts/ai_signal.py <文件>`（自动按 150–450 字分块，输出句长节奏/连接词/套话/缓和语/引用数据等信号）；
  3. 评估者结合 `references/aigc_signals_zh.md` 逐块判读：**风险等级**（高=AI 特征强 / 中=疑似 / 低=更像人写）、命中信号编号、缓和信号、修改优先级。
- 估算方法：高=1.0、中=0.5 加权 × 字符占比 → 估算总 AI 率（约 X%）+ 置信度，并声明估算非官方。
- 输出报告：块号｜风险等级｜命中特征｜缓和信号｜估算区间，加"优先级最高的待改段落清单"。
- 提示：摘要/Abstract、纯文献罗列段、方法学固定表述（如"采用双向固定效应模型"）结构化程度高，优先提示但**不作为主要改写目标**。

## 4. 阶段 ③：修改意见（先给方案，作者确认后才动手）

1. 确认目标比例（未给时默认 ≤10%；目标 <10% 需如实告知：约 10% 是中文学术语体实用下限，再低会明显损伤学术性）。
2. 按优先级列出修改意见清单，**不改写原文**：段落位置 → 原句摘录 → 命中的问题（信号编号）→ 具体改法（≤3 条）→ 不改的部分。
3. 作者确认范围（只改标红还是全文过一遍）后，进入逐段改写。计划优先，绝不未经确认一次性大改全文。

## 5. 阶段 ④：改写规则（摘要，细则见信号库四、五节）

**做**（核心：只动句法，少动词汇；变化节奏与密度；用真实证据做缓和信号）：

- 打破工整排比/三段式：`首先…其次…最后`→自然过渡；三元并列改为不对称（重要的多说，次要的简说）。
- 变化句长节奏：混入 10–18 字短句与 40+ 字带从句长句；拆 40+ 字长句于转折处。
- 术语不动，挪句法角色：避免术语总在主语位（"XX 是/具有"），移到宾语/状语/定语或用指代复指。
- 削减功能重叠连接词：同段同功能只留 1 个，其余删掉或用标点/句子逻辑承接。
- 删套话与段尾元话语收束：值得注意的是/总的来说/综上所述/具有重要意义/不可忽视 等。
- 去模糊归因：无出处的"专家认为/研究表明"改为本文判断或给具体来源。
- 注入作者视角：承认局限、表达意外、留判断（"笔者认为…"）。
- 泛化结论改可检验推论："具有重要意义"→可验证的命题。
- 写新内容按"预防性写作 8 条"（具体动词、长短句交替、不编号自然过渡、直接说事、去连接词、段长不均匀、用"而/则"、穿插 ≤10 字短句）——从源头避免，比事后修高效 5–10 倍。
- 有真实引用/数据/图表的段落，把证据放在显眼论证位置——比任何措辞技巧都有效。

**禁**：

- 换同义词（"显著"→"明显"）——检测器抓句法节奏，不抓词汇替换，无效。
- 全面口语化/网络化（会从"AI 腔"倒向"博客腔"）、删光"较为/往往/可能"等留余地学术语、给术语加引号制造距离感、为降率篡改数据或结论、一次大改全部段落导致信息密度全线下降。

## 6. 阶段 ⑤：复查与迭代（直到达标）

1. **硬约束自检表**（每段+全文，细则见信号库第六节）：AI 高频词每段 ≤2；段末总结套句全文 ≤1；整齐三元/四元并列每段 ≤1；"基于/依据XX理论"起笔段落 ≤20%；泛化结尾全文 0 处；模糊归因全文 0 处；正文加粗 ≤5 处。
2. **噪声预算**：每千字保留 2–3 处轻微 AI 特征作为自然噪声（如两项并列、程度较轻的过渡词全文 ≤1 处），**不要过度清洁**——全面均质化会触发另一类标记。同时复核：事实数字未变？术语未动？无新增编造？仍是学术语体？
3. 对改写后文本重跑 `ai_signal.py`，与改写前输出对比。
4. **再开独立评估者重估 AI 率**（同阶段②，不带改写记录）。新旧两份独立报告并排对比，如实汇报新估算与差距。
5. 未达标则只定点改当前最红的段落，循环 ③–⑤。达标后总结：改动段数/总字符、命中特征消除情况、估算前后对比、自查结论。

## 7. 阶段 ⑥：交付

- 逐段以"原文 → 改写文 → 改动说明"呈现。
- **精确导出 .docx**：用 `scripts/docx_write.py <定稿.txt> <输出.docx>` 把定稿原样装回 Word（支持 `#` 标题与 `**加粗**`），**不要**让任何工具"按主题重写"定稿内容。导出后用 `office_extract.py` 回读可复核逐字一致。
- 交付时提醒：**务必上知网等官方平台实测**；把官方仍标红的段落回传，进入二次精修（这是把 AI 率真正压下去的最有效方式）。

## 8. 误用与边界（务必让使用者知晓）

- 本方法解决的是"AI 辅助写作后语言风格趋同"的**表达层问题**；它不解决、也不应被用于掩盖：抄袭、代写、伪造数据、无出处引用等实质学术不端。
- 不同机构对生成式 AI 的披露要求不同，作者有义务按所在机构/期刊规定如实披露 AI 辅助情况。
- 检测阈值与算法随厂商更新而变化，任何估算都有时效；官方检测结果为准。
